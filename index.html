04 / BEHIND KHUKURI RUN

THE PEOPLE
BEHIND THE MILES.

Khukuri Run started with a simple idea - running feels different when it feels like you belong. These are the people helping shape that idea into something real.

FOUNDER

Ishan Basnet

Started Khukuri Run with the belief that a run club can be more than just the run - it can be a space where people show up, feel seen, and keep coming back for each other.

Usually thinking about the next run, the next idea, and whether post-run fun is essential. It is.

FOUNDING ADVISOR

Jenisha Magar

Lawyer, friend, and one of the early voices behind Khukuri Run - helping shape ideas, values and the kind of community we want this club to become.

Brings perspective, thoughtful advice, and the occasional “have you actually thought this through?” energy.
